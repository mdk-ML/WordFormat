# 📄 Word格式化工具（GB/T 9704-2012）

## 📋 工具简介

便捷的Word文档格式化工具，严格遵循GB/T 9704-2012标准，可快速完成文档格式标准化设置，无需手动逐一调整。

🔒 **全程本地运行，无文档内容泄露风险。**

---

### ⚙️ 添加脚本

> 💡 WPS可在VB环境或JS环境添加宏代码，以下2种环境**选择一种**进行添加即可。

#### 🔷 VB环境

**创建模块**
📌 打开WPS → 工具 → 开发工具 → 切换至VB环境 → 查看代码 → 右击Normal → 插入 → 模块

**复制脚本**
📋 复制脚本[Format2GBT9704_2012.bas](Format2GBT9704_2012.bas)中的内容，粘贴至模块1，关闭窗口即可。

---

#### 🟢 JS环境

**创建模块**
📌 打开WPS → 工具 → 开发工具 → 切换至JS环境 → 查看代码 → 右击Project(Normal.dotm) → 插入 → 模块

**复制脚本**
📋 复制脚本[Format2GBT9704_2012.js](Format2GBT9704_2012.js)中的内容，粘贴至Module1，关闭窗口即可。

![demo.gif](img/demo.gif)

---

### ▶️ 使用脚本

#### 1️⃣ 运行宏脚本
📌 打开WPS → 工具 → 运行宏 → 选择「Format2GBT9704_2012」→ 点击运行

> ⚠️ 因为WPS 宏引擎的 "懒加载" 设计，【运行宏】按钮可能是灰色的，需要手动先点击【开发工具】，此时会自动加载宏，再点击【运行宏】即可。

#### 2️⃣ 成功提示
✅ 运行成功后，将弹出「文档已按照GB/T 9704-2012格式化完成。」提示。

## 📐 可格式化具体内容

### 📏 页面设置

| 项目 | 设置值 |
|:---:|-------|
| 📏 页边距 | 上3.7cm、下3.5cm、左2.7cm、右2.7cm |
| 📊 行距 | 固定值28磅 |
| 🔢 页码 | 奇数页码居右，偶数页码居左，采用4号宋体阿拉伯数字 |

---

### 📝 格式标准

| 级别 | 字体 | 说明 |
|:---:|------|------|
| 🏷️ **标题** | 方正小标宋简体 二号 | 标题后空一行 |
| 1️⃣ **一级标题** | 黑体 三号 | 缩进2字符，序数：一、二、三... |
| 2️⃣ **二级标题** | 楷体_GB2312 三号 | 缩进2字符，序数：（一）（二）（三）... |
| 3️⃣ **三级标题** | 仿宋_GB2312 三号 | 缩进2字符，序数：1.2.3...，**加粗** |
| 4️⃣ **四级标题** | 仿宋_GB2312 三号 | 缩进2字符，序数：（1）（2）（3）...，**加粗** |
| ✨ **其他加粗** | - | "一是、二是"等表述统一加粗 |
| 📄 **正文** | 仿宋_GB2312 三号 | 首行缩进2字符 |
| 🔤 **数字** | Times New Roman | 英文和数字字体 |
