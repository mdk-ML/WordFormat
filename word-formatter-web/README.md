# Word格式化工具（Web版）

基于GB/T 9704-2012公文格式标准的Word文档格式化工具。

## 功能特性

### ✅ 已实现功能

1. **文本处理**
   - 标点符号标准化（英文→中文）
   - 空格处理（保留英文间空格，删除其他）
   - 句号智能替换（前后无数字时替换）
   - 引号区分左右

2. **标题识别与样式**
   - 一级标题：一、二、三...（黑体 三号）
   - 二级标题：（一）（二）（三）...（楷体_GB2312 三号）
   - 三级标题：1. 2. 3....（仿宋_GB2312 三号 加粗）
   - 四级标题：（1）（2）（3）...（仿宋_GB2312 三号 加粗）
   - 连续标题判断（排除正文）

3. **格式设置**
   - 页面边距：上3.7cm、下3.5cm、左2.8cm、右2.6cm
   - 行距：固定值28磅
   - 首行缩进：2字符
   - 首段标题：方正小标宋简体 二号 居中

4. **其他功能**
   - 自动编号删除
   - 特定前缀加粗（一是、二是等）
   - 批量处理多个文件
   - 批量下载（单文件直接下载，多文件打包zip）

### ⚠️ 当前限制

1. **页码设置**
   - 纯前端环境中设置页码比较复杂
   - 需要手动在Word中添加页码

2. **图片处理**
   - 能够识别图片段落
   - 图片段落保持原格式（不缩进，单倍行距）
   - 但可能无法完全保留所有图片属性

3. **表格处理**
   - 表格内容会被处理
   - 但表格结构可能受影响

4. **页眉页脚**
   - 当前版本不保留页眉页脚
   - 需要手动添加

5. **字体依赖**
   - 需要用户系统安装以下字体：
     - 仿宋_GB2312
     - 楷体_GB2312
     - 黑体
     - 方正小标宋简体
     - 宋体

## 技术栈

- **前端**：HTML5 + CSS3 + 原生JavaScript
- **文档解析**：jszip（读取.docx文件）
- **XML处理**：DOMParser（浏览器内置）
- **文档生成**：jszip（生成.docx文件）
- **文件下载**：FileSaver.js

## 使用方法

1. 打开 `index.html` 文件
2. 拖拽或选择 .docx 文件
3. 点击"开始处理"
4. 等待处理完成
5. 点击"批量下载"获取格式化后的文件

## 注意事项

1. **文件格式**：仅支持 .docx 格式（不支持 .doc）
2. **文件大小**：单文件最大10MB
3. **浏览器兼容**：需要现代浏览器（Chrome、Firefox、Edge等）
4. **离线使用**：所有代码和库文件本地化，可离线使用

## 与WPS宏脚本的区别

| 功能 | WPS宏脚本 | Web版 |
|------|----------|-------|
| 运行环境 | WPS Office | 浏览器 |
| .doc支持 | ✅ 支持 | ❌ 不支持 |
| 页码设置 | ✅ 支持 | ⚠️ 需手动 |
| 页眉页脚 | ✅ 支持 | ❌ 不保留 |
| 批量处理 | ❌ 不支持 | ✅ 支持 |
| 离线使用 | ✅ 支持 | ✅ 支持 |

## 开发说明

如需修改格式配置，请编辑 `js/config.js` 文件。

如需修改文本处理逻辑，请编辑 `js/text-utils.js` 文件。

如需修改标题识别逻辑，请编辑 `js/heading.js` 文件。
